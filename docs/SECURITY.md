# 安全与隐私

本补丁启动官方 Cline Desktop 的子进程，并仅向该子进程传入 WebView2 的 loopback CDP 参数：`--remote-debugging-address=127.0.0.1` 和一个临时端口。它不修改官方安装文件、注册表或系统环境变量。

启动器通过本机 CDP HTTP 发现端点和 WebSocket 将字典注入页面。端口只监听本机；请不要转发或共享该端口。能以相同用户权限在本机运行的其他进程理论上可以在端口存活期间访问 CDP，因此请只在可信设备和会话中运行。

启动器为本次运行创建锁文件，官方 Cline 退出后清理锁。若注入失败或收到 `SIGINT` / `SIGTERM`，启动器会终止其刚启动的官方直接子进程，并最多等待 5 秒后清理锁；不会查找或终止启动前已存在的其他 Cline 进程。Windows 控制台的 Ctrl+C 可传递 `SIGINT`，Node 交付的 `SIGTERM` 会进入同一清理流程。任务管理器的强制结束无法执行退出清理，但下一次启动会识别死 PID 并移除陈旧锁。

启动器只在 `--debug` 或 `CLINE_ZH_DEBUG=1` 时写入 `artifacts/launcher.debug.log`，内容限于本次启动的阶段、target 元数据、能力探测、心跳失败和退出清理。

图标使用本项目自有的 `ZH` 补丁图标。上游 Cline 仓库公开标注 Apache-2.0，但 Apache-2.0 第 6 节不授予产品名、商标或服务标志许可，因此本项目不把官方图标作为自己的再分发资产，也不暗示官方背书。

快捷方式安装只在当前用户桌面创建 `Cline 中文版.lnk`。卸载只删除该快捷方式；补丁项目目录须由用户自行删除。
