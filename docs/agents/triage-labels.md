# Triage Labels（中文）

各 skill 用五个标准 triage 角色表述。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库实际标签 | 含义 |
| -------------------------- | -------------- | ---- |
| `needs-triage`             | `needs-triage` | 需要维护者评估该 issue |
| `needs-info`               | `needs-info`   | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent` | 已充分描述，可交由 AFK agent 执行 |
| `ready-for-human`          | `ready-for-human` | 需要人工实现 |
| `wontfix`                  | `wontfix`      | 不予处理 |

当 skill 提到某个角色（例如“打上 AFK-ready 的 triage 标签”）时，请使用本表右列对应的标签字符串。

要求：标签操作附带的评论与说明一律使用中文。如需改用其它命名，请直接改右列。
